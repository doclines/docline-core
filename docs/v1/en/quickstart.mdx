# Quickstart

<Steps>
  <Step title="Install dependencies">Run `npm install` in the repository root.</Step>
  <Step title="Compile static docs">Run `npm run docs:compile`.</Step>
  <Step title="Start local preview">Run `npm run dev` and open the shown URL.</Step>
</Steps>

## Why static generation

All markdown and MDX are compiled ahead of time into static HTML and search data.
