## Quickstart Endpoint (Tabs)

<Tabs>
  <Tab title="curl">

```bash
curl -X POST https://api.example.com/v1/tickets \
  -H "Authorization: Bearer $DOCS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"Printer offline","priority":"high"}'
```

  </Tab>
  <Tab title="JavaScript">

```js
const response = await fetch('https://api.example.com/v1/tickets', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.DOCS_TOKEN}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ title: 'Printer offline', priority: 'high' }),
});

const data = await response.json();
console.log(data.id);
```

  </Tab>
  <Tab title="Python">

```python
import requests

response = requests.post(
    "https://api.example.com/v1/tickets",
    headers={"Authorization": f"Bearer {DOCS_TOKEN}"},
    json={"title": "Printer offline", "priority": "high"},
    timeout=10,
)

print(response.json()["id"])
```

  </Tab>
</Tabs>

## SQL + JSON Payload

```sql
SELECT id, title, status, updated_at
FROM tickets
WHERE status IN ('open', 'in_progress')
ORDER BY updated_at DESC
LIMIT 50;
```
