## JavaScript

```js
const token = process.env.DOCS_TOKEN ?? 'dev-token';
const safe = (value) => String(value).replace(/[<>"']/g, '_');
console.log(`token-length=${safe(token).length}`);
```

## SQL

```sql
SELECT p.slug, p.title, c.locale
FROM pages p
JOIN contexts c ON c.id = p.context_id
WHERE c.version = 'v2'
  AND c.locale IN ('es', 'en')
ORDER BY p.updated_at DESC
LIMIT 25;
```

## GraphQL

```graphql
query PageBySlug($slug: String!) {
  page(slug: $slug) {
    slug
    title
    blocks {
      __typename
      ... on CodeBlock {
        language
        code
      }
    }
  }
}
```
