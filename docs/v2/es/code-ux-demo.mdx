## Ejemplo API (Tabs)

<Tabs>
  <Tab title="curl">

```bash
curl -X PATCH https://api.example.com/v2/users/usr_20 \
  -H "Authorization: Bearer $DOCS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"active":true}'
```

  </Tab>
  <Tab title="Node">

```js
await fetch('https://api.example.com/v2/users/usr_20', {
  method: 'PATCH',
  headers: {
    Authorization: `Bearer ${process.env.DOCS_TOKEN}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ active: true }),
});
```

  </Tab>
</Tabs>
